## What I Learned

One of my biggest lessons from this stage was understanding how SQL can be used to turn questions into queries and queries into useful information.

I learned that writing a query is not only about knowing SQL syntax. It also requires understanding the structure of the data, choosing the right operations, and checking whether the results make sense.

The practical project helped reinforce these concepts by giving me opportunities to apply what I was learning throughout the SQL curriculum.

## Challenges and Learnings

SQL introduced a new way of thinking about data compared with spreadsheets.

I had to become comfortable working with databases, tables, relationships, queries, filters, functions, aggregations, and more advanced analytical techniques.

Working through the practical project also helped me identify areas where I needed to improve my understanding and gave me experience applying SQL concepts to real analytical problems.
